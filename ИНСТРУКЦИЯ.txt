ПУЛЬТ ДЛЯ ПРОГРАММЫ — ИНСТРУКЦИЯ
=================================

ЧТО В ПАПКЕ
  index.html            — сам пульт
  config.js             — подписи кнопок, цвета, список треков (меняйте здесь)
  tracks/pads/01..30.mp3 — треки для 30 пэдов (сейчас там демо-звуки)
  tracks/bg/01..10.mp3   — фоновые треки (сейчас демо)
  sw.js, manifest.webmanifest, icons/ — для работы офлайн и иконки, не трогать


1. ЗАМЕНИТЬ ТРЕКИ
  • Положите свои mp3 в tracks/pads/ с именами 01.mp3 … 30.mp3
    (01 = первая кнопка, 02 = вторая и т.д.).
  • Фон — в tracks/bg/ с именами 01.mp3 … 10.mp3.
  • Можно и свои имена файлов — тогда пропишите их в config.js (поле file).
  • Подписи и цвета кнопок — в config.js. Цвета: red, orange, yellow, green,
    cyan, blue, purple, pink, white.
  • После любых изменений увеличьте VERSION в config.js (1 → 2 → 3 …).


2. ВЫЛОЖИТЬ В ИНТЕРНЕТ (один раз, бесплатно) — GitHub Pages
  1) Зарегистрируйтесь на github.com.
  2) Создайте новый репозиторий (New repository), например pult, тип Public.
  3) Нажмите «uploading an existing file» и перетащите ВСЁ содержимое
     этой папки (не саму папку, а файлы и папки внутри). Commit changes.
  4) Settings → Pages → Source: «Deploy from a branch», Branch: main, / (root) → Save.
  5) Через 1–2 минуты появится ссылка вида  https://ВАШ_ЛОГИН.github.io/pult/
  Эту ссылку можно закрепить в Telegram-канале.

  Альтернатива без регистрации на GitHub: app.netlify.com/drop — перетащить папку.


3. УСТАНОВИТЬ НА ТЕЛЕФОН (нужен интернет один раз)
  ANDROID (Chrome):
    открыть ссылку → кнопка «Скачать и установить» → «Установить».
    Треки скачаются сами. В углу появится «Офлайн готов».
  IPHONE (только Safari!):
    открыть ссылку → «Поделиться» → «На экран Домой» →
    открыть пульт С НОВОЙ ИКОНКИ → «Скачать треки».
  Если ссылка открылась внутри Telegram — «⋯» → «Открыть в браузере».


4. КАК ПОЛЬЗОВАТЬСЯ
  • Пэд: нажал — играет, кнопка светится и заполняется цветом.
    Нажал ещё раз — стоп. Нажал другой — переключится.
    Сыгранные пэды получают ✓.
  • Фон: ▶ / ❚❚ и ⏭. Треки идут в случайном порядке и НЕ повторяются.
    Пока играет пэд, фон приглушается (на iPhone — ставится на паузу
    и продолжается после пэда).
  • Таймер: −1 / +1 / +5 минут, ▶ старт / ❚❚ пауза, ⟲ сброс.
    Ни с чем не связан. После нуля уходит в минус и мигает красным.
  • Меню ⋯ → «Новая программа» — снять все ✓ и снова разрешить весь фон.
  • Экран не гаснет, пока пульт открыт.


5. ПЕРЕД МЕРОПРИЯТИЕМ
  • Включить режим полёта, открыть пульт с иконки, проверить несколько пэдов и фон.
  • Зарядить телефон / держать на зарядке.
  • iPhone: блокировку экрана во время программы лучше не использовать
    (у Apple есть ограничения для сайтов на главном экране).
