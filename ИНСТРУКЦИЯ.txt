ПУЛЬТ ДЛЯ ПРОГРАММЫ — ИНСТРУКЦИЯ
=================================

ЧТО В ПАПКЕ
  index.html   — сам пульт
  data.json    — подписи, цвета и имена треков (меняется из режима бога 👑)
  config.js    — общие настройки (столбцы, таймер, пароль-хэш)
  tracks/      — треки пэдов (pads) и фона (bg)
  sw.js, manifest.webmanifest, icons/ — офлайн-режим и иконки, не трогать


1. ЗАГРУЗИТЬ НА GITHUB (репозиторий dj-pad)
  Add file → Upload files → перетащить всё содержимое папки → Commit changes.
  Сайт: https://z5njc2nb8w-ux.github.io/dj-pad/


2. СОЗДАТЬ КЛЮЧ ДОСТУПА (один раз, нужен для режима бога)
  1) github.com → ваша аватарка справа вверху → Settings
  2) Слева в самом низу → Developer settings
  3) Personal access tokens → Fine-grained tokens → Generate new token
  4) Token name: pult
     Expiration: максимальный срок (потом ключ можно перевыпустить)
  5) Repository access: Only select repositories → выбрать dj-pad
  6) Permissions → Repository permissions → Contents → Read and write
  7) Generate token → СКОПИРОВАТЬ ключ (начинается с github_pat_…)
     GitHub покажет его только один раз!
  8) В пульте: 👑 → пароль → ⚙︎ → вставить ключ → «Проверить и сохранить»

  НИКОГДА не вставляйте ключ в файлы на GitHub — репозиторий открытый.


3. РЕЖИМ БОГА 👑 (администратор, пароль Bublik25726)
  • 👑 рядом со скоростью → пароль.
  • Нажмите пэд → подпись, цвет, «🎵 Заменить» (трек из Файлов телефона),
    ▶ — прослушать. «Готово». Блок фона → названия и треки фона.
  • Жёлтая точка на пэде = не опубликовано. «⬆︎ Опубл.» — отправить на сайт.
  • ⚙︎ → «Пароль для диджеев» — задать один раз (после сохранения ключа).
  • 📨 — запросы от диджеев: ▶ прослушать, «Принять» (сразу публикуется)
    или «Отклонить». Красная точка на 👑 = есть новые запросы.
  • ⚙︎ → «Очистить историю» — раз в 1–2 месяца, если репозиторий разросся.

3а. РЕЖИМ ДИДЖЕЯ 🎧 (пароль для диджеев)
  • 👑 → пароль диджея. Меняете пэды и фон так же, как администратор.
  • «📨 Отправить» → имя → «Отправить». Нужен интернет.
  • Изменения появятся у всех после подтверждения администратором.
  • Ключ GitHub и аккаунт диджею НЕ нужны.

4. УСТАНОВКА НА ТЕЛЕФОН
  ANDROID (Chrome): ссылка → «Скачать и установить» → «Установить».
  IPHONE (Safari): «Поделиться» → «На экран Домой» → открыть С ИКОНКИ →
    «Скачать треки».


5. ПЕРЕД МЕРОПРИЯТИЕМ
  • Открыть пульт с интернетом (подтянутся последние треки),
    дождаться «Офлайн готов».
  • Режим полёта → проверить пэды и фон.
